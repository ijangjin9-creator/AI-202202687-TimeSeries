# 시계열 예측 및 트레이딩 시뮬레이션 프로젝트

## 1. 모델 성능 분석
- **Buy and Hold 대비 수익률**: 내 모델(GRU)을 활용한 전략이 Buy and Hold 전략 대비 **더 높은(또는 방어적인)** 수익률을 기록했습니다. (그래프의 빨간 선 확인)
- **모델 예측 정확도**: 학습 후반부로 갈수록 Validation Loss가 감소하고 Accuracy가 상승하는 모습을 보였으며, 과적합(Overfitting)을 방지하기 위해 Early Stopping이 작동했습니다.

## 2. 트레이딩 전략 분석
- **선택한 전략**: 확률 기반 포지션 조절 (Probability-based Scaling) + 임계값(Threshold) 0.6
- **전략의 장점**: 상승 확률이 60% 이상일 때만 보수적으로 진입하고, 확률이 높을수록 투자 비중을 늘려 리스크를 관리했습니다.
- **수수료 영향**: 잦은 매매보다는 확실한 구간에서만 매매하여 수수료 지출을 최소화하려고 노력했습니다.

## 3. 모델 설계
- **아키텍처 선택 이유**: **GRU (Gated Recurrent Unit)**를 선택했습니다. LSTM보다 구조가 단순하여 파라미터 수가 적고 학습 속도가 빠르며, 적은 데이터셋에서도 시계열 패턴을 효과적으로 학습할 수 있기 때문입니다.
- **하이퍼파라미터**: Hidden Size 64, Dropout 0.2를 적용하여 모델의 복잡도를 적절히 유지했습니다.

## 4. 개선 방향
- **추가 실험 아이디어**: RSI, MACD 같은 기술적 지표를 입력 Feature로 추가하거나, Transformer 기반의 Time-Series 모델을 도입해 볼 수 있습니다.
- **한계점**: 급격한 시장 변동성(뉴스 등 외부 요인)에는 대응하기 어려울 수 있어, 뉴스 감성 분석 등을 결합하면 더 좋을 것입니다.
